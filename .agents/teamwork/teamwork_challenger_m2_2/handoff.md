## 2. Logic Chain

1. **Mathematical Accuracy**:
   - The formula specifies base 100 with deductions: $D = 15 \times \text{MustFix} + 7 \times \text{ShouldFix} + 3 \times \text{Tip}$.
   - We verified that the oracle function yields exact expected values across 11 edge test cases (e.g. 1H, 1M, 1L = 75; 0H, 1M, 1L = 90; 7H = 0 clamped).
   - In `ScoreBadge.tsx`, the formula is prominently rendered in the breakdown popover (`Base: 100 pts`, `Must Fix (High): -15`, `Should Fix (Medium): -7`, `Tip (Low): -3`). When `issuesCount` is passed, itemized counts `${count} × -N pts` are accurately formatted.
2. **Status Labeling & Edge-Case Robustness**:
   - Tested edge-case scores `-15, 0, 59, 60, 84, 85, 100, 105` and extreme values (`-1000, 9999, NaN, float boundaries 59.9999, 84.9999`).
   - All strictly mapped to the 3 designated statuses:
     - Score $< 60$: `"Needs attention (<60)"` (rose theme, `AlertOctagon`).
     - $60 \le \text{Score} < 85$: `"Needs a few tweaks (60-84)"` (amber theme, `AlertTriangle`).
     - $\text{Score} \ge 85$: `"Ready to share (85-100)"` (emerald theme, `ShieldCheck`).
   - None of the inputs threw runtime errors; SSR and browser DOM rendering completed cleanly.
3. **Keyboard & Event Interaction**:
   - Trigger buttons capture both `Enter` and Space (`' '`) in `onKeyDown`, invoke `e.preventDefault()`, and toggle disclosure state.
   - A document `keydown` listener intercepts `Escape` to close the popover.
   - An outside click handler on document `mousedown` accurately checks `containerRef.current.contains(e.target)` to close the popover on clicks outside while retaining it on clicks inside.
4. **Screen-Reader Semantics**:

   - Checked `aria-haspopup="dialog"` on `sm` and `md`.
